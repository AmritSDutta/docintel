# DocIntel Overview

DocIntel is an enterprise-grade multimodal Retrieval-Augmented Generation (RAG) system built with **Spring Boot 3.5.8** and **Spring AI 1.1.0**. It orchestrates multimodal PDF ingestion, structured content extraction, dense vector embeddings, hybrid chat pipelines, and automated groundedness and relevancy evaluation.

## Key Capabilities

- **Multimodal PDF Parsing**: Extracts structured text, tabular data in Markdown, image/chart captions, and raw JSON blocks directly via Google Gemini 2.5 Flash.
- **Vector Search & Storage**: Embeds extracted document segments using Google GenAI `text-embedding-004` (768 dimensions) and indexes them in Qdrant with HNSW similarity search.
- **Hybrid Chat Pipelines**: Provides both synchronous retrieval-augmented chat (`/ai/chat`) with session memory and reactive streaming chat (`/ai/reactive_chat`) with Model Context Protocol (MCP) tool integration.
- **Automated Verification & Evaluation**: Enforces factual groundedness and query relevancy using dual evaluators (`RelevancyEvaluator` and a custom `GroundedRelevantEvaluator`) powered by OpenAI GPT-5 Nano.
- **Recursive Query Refinement**: Employs an `EvaluationRecursiveAdvisor` to recursively re-prompt the LLM when an answer fails quality standards.
